# Web Development Course Studio

A mobile-first learning app for four complete learning tracks: Full-stack Web Development, Python, Excel, and Power BI.

## Run locally
Open `index.html` in a browser, or serve this folder with any static HTTP server.

## Publish with GitHub Pages
In repository **Settings → Pages**, choose **Deploy from a branch**, select the default branch and `/(root)`, then save.

## Curriculum source
The uploaded Master Syllabus is the curriculum authority. The starter interface maps its four tracks and four phases. Detailed lesson content, activities, assessments, and persistence are planned next; this initial scaffold does not claim the full syllabus content is already authored.

## Current architecture
- Static HTML, CSS, and JavaScript; no build step.
- Curriculum data in `data/curriculum.json`.
- Responsive interface with local phase selection and search.
- Progress is not yet persisted.
