    GUIDED LESSON · FULL-STACK FOUNDATIONS

    Semantic HTML and accessible structure

    Learn how to give web content meaning before styling it.

    1. What is semantic HTML?

    Semantic HTML uses elements that describe the role of their content. A page heading belongs in a heading element, navigation belongs in a navigation landmark, and the main content belongs in the main landmark. This helps browsers, assistive technologies, and other developers understand the page structure.

    2. Start with a meaningful page outline

    Use one main content area for the page’s primary content. Use headings in a logical order, and choose elements for their meaning rather than their default appearance.

    <header>
  <h1>Field Notes</h1>
</header>
<nav aria-label="Main">
  <a href="#articles">Articles</a>
</nav>
<main id="articles">
  <article>
    <h2>First article</h2>
    <p>A short introduction.</p>
  </article>
</main>
    3. Accessibility check

    Ask whether the element’s purpose is clear without relying on its visual styling. Links should describe their destination, form controls need programmatic labels, and keyboard focus must remain visible.

    Try it

    Sketch a simple article page with a site header, a navigation area, a main region, and one article. Choose semantic elements for each part and explain why you chose them.
